Box-Cox pada Data Hasil Differencing

Data hasil differencing memiliki nilai negatif dan nol, sedangkan transformasi Box-Cox mensyaratkan data positif. Karena itu data digeser dengan konstanta \(c = |\min| + 1\) = 726 sebelum dicek.

index.diff <- seq(1:length(train.diff))

# geser data agar seluruh nilai positif
c.shift <- if (min(train.diff) <= 0) abs(min(train.diff)) + 1 else 0
train.diff.shift <- train.diff + c.shift

bc.diff <- boxcox(train.diff.shift ~ index.diff, lambda = seq(-2, 2, by = 0.01))

lambda.diff <- bc.diff$x[which.max(bc.diff$y)]
lambda.diff
## [1] 1.05
ci.diff <- bc.diff$x[bc.diff$y > max(bc.diff$y) - 0.5 * qchisq(0.95, df = 1)]
c(Batas_Bawah = min(ci.diff), Batas_Atas = max(ci.diff))
## Batas_Bawah  Batas_Atas 
##        0.92        1.19

Pada data hasil differencing, nilai \(\lambda\) optimum sebesar 1,05 dengan selang kepercayaan 95% [0,92 ; 1,19]. Selang tersebut memuat angka 1, sehingga data hasil differencing stasioner dalam ragam dan tidak diperlukan transformasi. Dengan demikian, penanganan yang dibutuhkan hanya differencing satu kali, sehingga model yang dibentuk berbentuk ARIMA(p,1,q).

Dari plot ACF dan PACF data hasil differencing:

  • ACF: lag 1 (-0,119) dan lag 2 (-0,067) melewati batas signifikansi (±0,055), kemudian cuts off setelah lag 2. Jika PACF dianggap tails off, model tentatifnya ARIMA(0,1,2). Jika hanya lag 1 yang dianggap bermakna, modelnya ARIMA(0,1,1).
  • PACF: lag 1 (-0,119) dan lag 2 (-0,082) signifikan, kemudian cuts off setelah lag 2. Jika ACF dianggap tails off, model tentatifnya ARIMA(2,1,0). Jika hanya lag 1 yang dianggap bermakna, modelnya ARIMA(1,1,0).
  • Jika ACF dan PACF sama-sama dianggap tails off, model tentatifnya ARIMA(1,1,1).

Beberapa lag yang melewati batas pada lag yang lebih jauh (misalnya lag 10 dan 18) bersifat terisolasi dan masih wajar terjadi secara kebetulan, sebab dengan taraf 5% sekitar 1 dari 20 lag akan melewati batas.

Ringkasan AIC

sig.armaq <- function(m) {
  ct <- lmtest::coeftest(m)
  ct <- ct[rownames(ct) != "intercept", , drop = FALSE]
  if (all(ct[, 4] < 0.05)) "Ya" else "Tidak"
}

Uji Formal

Normalitas Sisaan

\(H_0\) : sisaan menyebar normal

\(H_1\) : sisaan tidak menyebar normal

Uji Kolmogorov-Smirnov dilakukan terhadap sebaran normal dengan rataan dan simpangan baku yang diduga dari sisaan itu sendiri. Argumen mean dan sd wajib diisi, sebab tanpa keduanya ks.test(..., "pnorm") membandingkan sisaan dengan N(0,1) yang pasti ditolak ketika skala data besar seperti harga saham.

Akurasi Peramalan

akurasi <- function(aktual, ramalan) {
  e <- as.numeric(aktual) - as.numeric(ramalan)
  c(ME = mean(e), RMSE = sqrt(mean(e^2)), MAE = mean(abs(e)),
    MAPE = mean(abs(e / as.numeric(aktual))) * 100)
}

Pada data uji, model akhir ARIMA(2,1,0) tanpa drift menghasilkan RMSE Rp1571, MAE Rp1229, dan MAPE 18,6%. Beberapa hal yang dapat disimpulkan:

  • Tanpa drift lebih baik daripada dengan drift (RMSE Rp1841; MAPE 22,2%). Intersep yang tidak signifikan membuat ramalan terus naik, berlawanan dengan arah harga yang sebenarnya turun. Ini mendukung keputusan membuang intersep.
  • Model hanya sedikit lebih baik daripada pembanding naif (RMSE Rp1610). Itu sejalan dengan temuan bahwa harga saham mendekati random walk: struktur AR(2) yang kecil hampir tidak menambah akurasi pada horizon panjang.
  • Nilai ME negatif (-1129) menunjukkan ramalan secara sistematis lebih tinggi daripada aktual. Penyebabnya adalah penurunan harga yang tajam pada periode uji, yaitu perubahan arah tren yang tidak mungkin ditangkap oleh model yang dilatih pada data hingga 23 April 2025.
  • Evaluasi pada horizon 320 hari (sekitar 15 bulan bursa) tanpa pembaruan data sangat berat bagi model univariat mana pun. Untuk penggunaan praktis, model sebaiknya diperbarui secara berkala dan ramalan dipakai untuk horizon pendek.

Kesimpulan

  1. Data latih BBCA (n = 1280) tidak stasioner dalam rataan (ACF turun lambat; ADF p-value = 0,28). Setelah differencing satu kali, data stasioner dalam rataan (ADF p-value ≤ 0,01). Pada data hasil differencing, selang Box-Cox [0,92 ; 1,19] memuat 1, sehingga ragam sudah stasioner dan tidak perlu transformasi.
  2. Dari ACF, PACF, dan EACF diperoleh lima model tentatif. ARIMA(2,1,0) dipilih karena AIC terkecil (15926.79) dengan seluruh parameter AR signifikan.
  3. Sisaan model saling bebas dan bernilai tengah nol, tetapi tidak normal dan ragamnya tidak homogen (efek ARCH).
  4. Overfitting (ARIMA(3,1,0) dan ARIMA(2,1,1)) tidak memperbaiki AIC dan parameter tambahannya tidak signifikan, sehingga ARIMA(2,1,0) dipertahankan. Karena intersep tidak signifikan, model akhir adalah ARIMA(2,1,0) tanpa drift.
  5. Ramalan 320 hari ke depan berbentuk hampir mendatar. Akurasi pada data uji rendah (MAPE 18,6%) karena harga BBCA turun tajam pada periode uji dan harga saham sangat mendekati random walk. Pemodelan ragam (ARIMA-GARCH) dan pembaruan model secara berkala dapat menjadi pengembangan lanjutan. ```
